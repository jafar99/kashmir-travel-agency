# Kashmir Travel Agency Website

A modern React-based travel agency website for Kashmir tourism featuring animated UI and comprehensive travel packages.

## Features

- Modern, responsive design with animations using Framer Motion
- Interactive package details with day-wise itineraries
- Image galleries using Embla Carousel
- WhatsApp integration for booking enquiries
- Real-time package filtering and sorting
- Mobile-friendly navigation
- Animated UI components with shadcn/ui

## Tech Stack

- React with TypeScript
- Tailwind CSS for styling
- Framer Motion for animations
- shadcn/ui components
- Embla Carousel for image galleries
- Express.js backend
- Wouter for routing

## Getting Started

1. Clone the repository
2. Install dependencies:
```bash
npm install
```
3. Start the development server:
```bash
npm run dev
```

## Project Structure

- `/client` - Frontend React application
- `/server` - Express.js backend
- `/shared` - Shared types and utilities
